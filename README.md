# SONDERA — Architectural Hospitality

A premium hospitality website concept for an off-grid architectural retreat in the California High Desert.

## Live Demo
https://sondera-hospitality.netlify.app

## Overview
SONDERA is a modern hospitality website concept designed to showcase a collection of architectural desert pavilions. The website focuses on minimalist design, immersive imagery, responsive layouts and an interactive reservation experience.

## Features
- Responsive navigation and mobile menu
- Architectural pavilion showcases
- Interactive pavilion selection
- Dynamic guest selection
- Check-in and check-out date validation
- Automatic reservation price and tax calculations
- Reservation confirmation modal
- Scroll-triggered animations

## Technologies
- HTML5
- CSS3
- Vanilla JavaScript

## Project Structure
- index.html — Website structure
- style.css — Styling and responsive layouts
- main.js — Interactive functionality
- assets/ — Project images and resources

## Project Status
Completed frontend demonstration project.

Note: The reservation interface is a frontend demonstration and does not process real bookings or payments.
